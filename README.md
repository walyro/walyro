# Walyro

**Turn your own videos into live Mac wallpapers.**

Walyro is a native macOS app that plays a video you own behind your desktop,
like a clip from a trip or a timelapse you shot. Everything stays on your Mac.

## Features

| | |
| --- | --- |
| **Your videos** | Drag in any video and it becomes your wallpaper |
| **Built-in loops** | Ready-made wallpapers, if you'd rather not supply your own |
| **Playlists** | Group wallpapers and switch between them |
| **Multi-display** | A different wallpaper on each screen |
| **Playback** | Fit, fill, or crop; volume; pause and resume |
| **Battery aware** | Optional auto-pause on battery or in Low Power Mode, plus a frame rate cap |

---

## Requirements

macOS 14.0 (Sonoma) or newer.
